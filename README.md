# UK Tech & Gaming YouTube Channel Research

Python tool that uses the YouTube Data API to find and rank UK tech and gaming review channels.

## What it does
- Searches 17 keyword queries (tech and gaming reviews)
- Removes duplicate channels
- Collects subscribers, video count and country
- Filters UK channels with relevant keywords
- Exports the top 500 channels ranked by subscribers to Excel

## Tools
Python, Pandas, YouTube Data API v3

## Note
API key AND filepath removed. Set your own key as an environment variable YOUTUBE_API_KEY.
